# validated-examples

이 디렉토리의 예제는 전부 `../core-grammar.md`의 **자가점검 9항**을 통과한 상태로 검증된 완성 프롬프트다. 각 파일은 그 자체로 복사-실행 가능한 완성본이며, 상단 주석(용도/레인/사이즈/검증) 아래의 본문이 곧 API에 넘길 프롬프트 문자열이다. 새 프롬프트를 작성할 때 "이 정도 밀도와 구조면 자가점검을 통과한다"는 기준점으로 참고한다. 여기 실린 프롬프트는 전부 이 스킬을 위해 새로 합성한 것이며, 외부 수집 코퍼스의 문장을 그대로 복사한 것이 아니다.

## 파일 목록

| 파일 | 레인 | 사이즈 / AR | 용도 |
|---|---|---|---|
| `drama_scene_still.txt` | drama | AR 4:5 (1024x1536) | 로우키 감정 리액션 컷, 8슬롯 시네마틱 태그소노미 구조 |
| `drama_sequence_4shot.txt` | drama | AR 16:9 (1792x1024) | Thinking 모드 연속 4샷, 공유 아이덴티티/환경 전문 포함 |
| `mv_mood_frame.txt` | music-video | AR 9:16 (1024x1792) | 아나모픽/필름그레인 계열 룩의 무드 프레임 단일 컷 |
| `commercial_product_hero.txt` | commercial | AR 1:1 (1024x1024) | 제품 히어로샷, HEX 팔레트 락, 하단 1/3 카피 여백 |
| `commercial_poster_copy.txt` | commercial | 2048x2048 (AR 1:1) | 한글 카피 렌더 포스터, 존/역할 라벨 문법 + Tier-1 동결 문장 |
| `editorial_fashion.txt` | editorial | AR 3:4 (1024x1536) | waist-up 85mm 결과 서술, 룩 프리셋 드롭인, 가상 모델 디스클레이머 |
| `edit_change_only.txt` | edit-workflows | AR 3:2 (1536x1024) | "Change only X" + 보존 락리스트 템플릿 실사용 |
| `character_sheet_3view.txt` | character-consistency | 2048x2048 (AR 1:1) | 3면도 캐릭터 시트, pure white background, 불변항 명세 |

## 공통 규칙 (전 파일 적용)

- **Tier-0/Tier-1**: 장면 배제는 전부 긍정 재서술이며 자유 네거티브는 0개다. 텍스트가 실제로 렌더되는 컷(`commercial_poster_copy.txt`)에만 Tier-1 결합 문장이 `AR` 토큰 직전에 정확히 1회 붙는다. 텍스트가 없는 나머지 7개 컷에는 이 문장이 붙지 않는다.
- **죽은말 0개**: "예쁘게/고급스럽게" 류 무대 지정어 대신 수치화·몸 반응 드롭인·구체 예시 세 경로 중 하나로 전부 환원했다.
- **수치 앵커링**: 팔레트는 컷당 HEX 3~5개, 색온도는 켈빈 또는 warm/neutral/cool 3단, 조명비는 key:fill 숫자 비율 + 결과 서술 병기로 못박았다.
- **장비 → 결과 환원**: 카메라·렌즈·조명기 브랜드명은 어디에도 남기지 않았다. 필요한 경우에만 `lens character:` 라벨 뒤에 결과 서술을 붙였다.
- **사이즈 락**: 8개 파일 모두 6종 화이트리스트 안의 값만 썼고 `auto`는 쓰지 않았다. 6종 버킷을 골고루 순회하도록 배분했다.
- **1컷=1콜**: `drama_sequence_4shot.txt`는 Thinking 모드로 4장의 독립 파일을 생성하는 문서화된 패턴이며 단일 캔버스 그리드가 아니다. `character_sheet_3view.txt`는 "그 컷 타입의 정의상 원래 여러 뷰가 한 장면인" 스타일가이드 시트류 예외에 해당한다. 나머지 6개는 순수 1컷=1콜이다.
- **한/영 혼용**: 서사 골격·문화 부하 명사는 한국어, 심도·조명·필름 에뮬레이션·포즈 술어는 영어로 통일했고, 렌더되는 따옴표 문자열 안에서는 한 문자열에 한 언어만 썼다.
- **실재 상표·실존 인물 금지**: 모든 인물은 가상 오리지널 캐릭터이며, 실사 모델이 등장하는 컷(`editorial_fashion.txt`)에는 가상 모델 디스클레이머를 명시했다.
