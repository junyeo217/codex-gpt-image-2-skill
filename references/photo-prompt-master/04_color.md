# PART IV. 색 (COLOR)

## 11. 색채 이론

### 색 체계
- `Munsell color system (hue/value/chroma)`
- `Itten color wheel` — 12색 균형
- `Goethe color wheel`
- `Albers color interaction` — 상대적 색 인지
- `Pantone reference`

### 색 조화
- `complementary (보색)` — 빨강/시안 등
- `split-complementary`
- `analogous (인접색)`
- `triadic` — 정삼각 3색
- `tetradic / square` — 4색
- `monochromatic (단색조)`

### 색 대비
- `simultaneous contrast` — 인접색이 인지에 영향
- `successive contrast` — 잔상
- `hue contrast / value contrast / chroma contrast`
- `cool vs warm contrast`
- `Bezold effect`

### 인지 / 메모리 컬러
- `memory color (skin/sky/foliage)` — 사람이 기억하는 표준색
- `skin tone protection`
- `Caucasian / Asian / dark skin tone calibration`

## 12. 색공간 & 로그 감마

### 색공간
- `sRGB` — 웹 표준
- `Adobe RGB (1998)` — 인쇄용 광색역
- `ProPhoto RGB` — 가장 넓음, RAW 후보정
- `DCI-P3` — 시네마 / 모던 디스플레이
- `Rec.709` — HD TV
- `Rec.2020` — UHD/HDR
- `ACES color space` — 시네마 워크플로
- `bt.2100 HDR`

### 로그 감마 (시네마 색관리)
- `S-Log3 (Sony)`
- `V-Log (Panasonic)`
- `Log-C (ARRI)`
- `RedLogFilm / Log3G10`
- `C-Log / C-Log3 (Canon)`
- `N-Log (Nikon)`
- `F-Log (Fujifilm)`

### 비트뎁스 / HDR
- `8-bit / 10-bit / 12-bit color`
- `HDR10` / `Dolby Vision` / `HLG`
- `peak nits 1000/4000/10000`
