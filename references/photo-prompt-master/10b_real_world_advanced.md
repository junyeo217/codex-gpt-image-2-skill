## 38. 플래시 / 스트로보 설정

### 출력 분수 (Power Ratio)
`1/1 (full) → 1/2 → 1/4 → 1/8 → 1/16 → 1/32 → 1/64 → 1/128 → 1/256`

### 출력 (Watt-seconds, Joules)
- `100Ws` — 작은 모노블록
- `250Ws` — 인물 표준 (Profoto B10)
- `500Ws` — 표준 (B1X, Broncolor Siros)
- `1000Ws` — 패션
- `2400Ws` — 광고 / 자동차
- `4800Ws` — 대형 (Pro-11)

### 동조 속도 (Sync Speed)
- `1/200s` — Sony, Canon (구형)
- `1/250s` — 표준
- `1/320s` — Nikon (전자식)
- `1/8000s` — HSS (High-Speed Sync)
- `Hypersync` — Pocket Wizard 트릭

### Guide Number (GN)
- `GN 30 (m, ISO 100)` — 일반 스피드라이트
- `GN 60` — 강력한 외장 플래시
