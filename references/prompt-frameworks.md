# Prompt Frameworks (Tombstone)

이 파일의 내용은 리포지토리 재구조화로 아래 새 레퍼런스 레이어에 분산 흡수되었다. 새 진입점은 `SKILL.md`의 라우팅 표다 — 여기로 돌아오지 말고 표에서 매칭 행을 찾아 해당 파일을 로드한다.

| 예전 내용 (`prompt-frameworks.md`) | 새 위치 |
|---|---|
| 11-slot stack, Subject+Context+Style 초안 골격, Cinematic/Photography 캡처 언어 | `references/core-grammar.md` (수치 앵커링) + `references/cinematic-stills.md` (8슬롯 태그소노미) + `references/photo-prompt-master/` |
| Text rendering 규칙 | `references/text-in-image.md` |
| Official Cookbook tuning rules | `references/model-facts.md` + `references/api-and-codex-routes.md` |
| Product/ad, Character concept 골격 | `references/lanes/commercial.md` + `references/character-consistency.md` |
| Use-case playbook(인포그래픽/번역/포토리얼/로고/광고/만화/UI/제품샷 등) | `references/lanes/` (드라마/뮤직비디오/커머셜/에디토리얼) + `references/text-in-image.md` |
| Edit and reference workflows(스타일 전이/가상 피팅/오브젝트 제거·삽입/멀티이미지 합성 등) | `references/edit-workflows.md` |
| Iteration by subtraction(실패 슬롯 진단) | `references/core-grammar.md`의 자가점검 9항 |

원문은 더 이상 이 파일에 없다. 필요한 세부 어휘는 위 매핑을 따라 해당 레퍼런스를 직접 연다.
